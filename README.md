
# Network Traffic Analysis

## Project Overview

This project documents my first hands-on network traffic analysis exercise as part of my cybersecurity learning journey.

I used Linux and tcpdump to capture and inspect network traffic, apply filters, and record my observations.

## Objectives

- Practise using the Linux command line.
- Capture and inspect network packets with tcpdump.
- Observe different network protocols.
- Apply a TCP filter and document the results.
- Write a report based on the observed traffic.

## Tools Used

- Ubuntu Linux through WSL
- tcpdump
- Linux terminal commands

## Analysis and Findings

During my initial analysis, I recorded 14 packet records.

The observed traffic included:

- **ARP:** Activity related to resolving network addresses.
- **NTP over UDP:** Traffic related to network time synchronization.
- **TCP filter:** No matching packets were displayed during this test.

## What I Learned

- How to start a packet capture with tcpdump.
- How to apply a protocol filter.
- How to recognize ARP and NTP traffic.
- How to document technical observations.
- Why network captures should be reviewed for sensitive information before sharing.

## Evidence

A report and supporting evidence were created during the exercise.

Sensitive packet captures are not included in this public project.
